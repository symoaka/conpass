# ConPass

ConPass is a Discord FAQ, insights, and leveling bot with a Streamlit dashboard.

## Features
- SQLite-backed FAQ slash commands.
- Command usage insights.
- Configurable per-server leveling.
- `/rank`, `/leaderboard`, and `/levelconfig` Discord commands.
- Configurable level-up announcements and role rewards.
- Dashboard controls for FAQs, insights, leveling settings, and rewards.
- Configurable bot presence.

## Quick Start
1. Copy `.env.example` to `.env`.
2. Add your Discord bot token to `.env`.
3. Run the launcher:

```bash
./start.sh
```

The dashboard and bot setup details live in [INSTRUCTIONS.md](INSTRUCTIONS.md).
